# Customer_Behavior_Analysis
Data analytics project basis on Customer behavior

Overview

This project demonstrates an end-to-end Data Analytics workflow, starting from data loading and preprocessing to visualization and reporting. The project focuses on extracting meaningful insights from raw data using Python, SQL, and Power BI.

The workflow includes:

Loading and exploring datasets using Python
Performing Exploratory Data Analysis (EDA)
Cleaning and transforming data
Running SQL queries using PostgreSQL/MySQL/SQL Server
Building interactive dashboards in Power BI
Creating analytical reports and presentation slides

This project highlights practical data analytics skills used in real-world business environments.
